# Raymond Klanderman Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Vite. This portfolio showcases my professional experience, projects, and skills in web development and AI.

## Features

- Modern React + TypeScript implementation
- Responsive design with SCSS
- Smooth animations using Framer Motion
- Contact form integration with Formspree
- Component-based architecture
- Fast development with Vite

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
